# HN Radial 正式训练

使用 `configs/hn_radial_learn_img_formal.yaml` 从随机初始化开始训练。数据按受试者划分：
sub-01 至 sub-07 训练，sub-08 验证，sub-09 至 sub-10 留作测试。每个体数据只读取
Python `[112:176]`，即解剖层面 113 至 176。数据不会被复制或改写。

配置为单卡、batch size 1、FP32、Adam 1e-4、最多 150 epoch。验证复数 MSE
决定最佳权重；验证损失连续 8 epoch 不改善后降低学习率，连续 25 epoch
不改善后提前停止。模型是 32 基础通道的 LEARN-IMG U-Net，上采样激活与旧版
TensorFlow 一致。输入和参考使用同一个输入尺度归一化。

## 在 tmux 中手动启动

先在普通终端确认空闲显卡：

```bash
nvidia-smi
tmux new -s learn-img-formal
```

进入 tmux 后执行（下面的 `2` 是显卡编号示例，启动前按空闲情况修改）：

```bash
cd /data/home/gcjiang3/qsm/LEARN
mkdir -p results
set -o pipefail
CUDA_VISIBLE_DEVICES=2 /data1/gcjiang3/envs/LEARN/bin/python -u scripts/train_learn_img.py \
  --config configs/hn_radial_learn_img_formal.yaml --device cuda:0 \
  2>&1 | tee results/hn-radial-learn-img-formal.log
```

`CUDA_VISIBLE_DEVICES=2` 将物理显卡 2 映射为进程内的 `cuda:0`。
按 `Ctrl+B` 再按 `D` 退出 tmux 显示，训练继续运行。重新进入：

```bash
tmux attach -t learn-img-formal
```

日志在 `results/hn-radial-learn-img-formal.log`；每个 epoch 的结构化记录在
`results/hn-radial-learn-img-formal/history.jsonl`。同一目录中还有
`latest.pt`、按验证 MSE 选出的 `best-loss.pt` 和固定验证样本
`best-validation.png`。预览图的三栏为污染输入、预测、零运动参考；
验证集是 sub-08，测试集未参与选模。

若训练意外中断，用相同配置和设备参数，并加上
`--resume results/hn-radial-learn-img-formal/latest.pt` 恢复。
不带 `--resume` 时，脚本会拒绝写入已有非空输出目录。

## 测试集评估

使用验证集选出的 `best-loss.pt` 一次性推理和评估 sub-09、sub-10：

```bash
cd /data/home/gcjiang3/qsm/LEARN
/data1/gcjiang3/envs/LEARN/bin/python scripts/evaluate_learn_img.py \
  --config configs/hn_radial_learn_img_formal.yaml \
  --checkpoint results/hn-radial-learn-img-formal/best-loss.pt \
  --device cuda:0
```

结果默认位于 `results/hn-radial-learn-img-formal/test-evaluation/`：
`summary.json` 给出总体、受试者和运动类型汇总；`per_pair.csv`、`per_slice.csv`
保留每个案例和层面的指标；`previews/` 存放每个案例第 141 层的四回波对比图。
脚本不写出预测体数据。复数 MSE 使用训练时的归一化与掩膜约定，幅值 PSNR
使用归一化图像的固定峰值 1；比较输入和预测时应在同一指标内比较。
已有非空输出目录会导致脚本拒绝覆盖，重复评估时需指定新的 `--output-dir`。
