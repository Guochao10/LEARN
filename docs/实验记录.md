# 实验记录

本文档记录 LEARN-IMG PyTorch 版本中影响训练方法和结果的实验改动。模型权重和训练日志不放入 Git；每次实验使用独立的输出目录，避免覆盖已有结果。

## 当前数据和共同设置

- 数据：`HNRepeatability_RadialMotion_v1`
- 训练层面：解剖第 113--176 层，对应 Python 切片 `[112:176]`
- 数据划分：按受试者划分训练、验证和测试集
- 输入：复数图像的实部和虚部，4 个回波
- 指标：复数 MSE、幅度 PSNR、SNR，以及按运动类型统计的指标

## 实验 1：正式基线

- 配置：`configs/hn_radial_learn_img_formal.yaml`
- 输出：`results/hn-radial-learn-img-formal`
- 网络：普通 U-Net 映射，`residual: false`
- 基础通道数：32
- 损失：全图复数 MSE
- 脑掩膜：未启用

该实验作为后续实验的比较基线。

## 实验 2：残差校正

- 配置：`configs/hn_radial_learn_img_residual.yaml`
- 输出：`results/hn-radial-learn-img-residual`
- 改动：将网络输出解释为校正量，并从输入中减去校正量：

  `prediction = input - correction`

- 初始化：残差输出层权重和偏置初始化为零，使训练开始时网络近似恒等映射
- 其他训练设置保持与正式基线一致

目的：减少对轻度污染输入的不必要修改，改善输入已经较清晰时的过度校正。

## 实验 3：残差校正加脑掩膜损失

- 配置：`configs/hn_radial_learn_img_residual_masked.yaml`
- 输出：`results/hn-radial-learn-img-residual-masked`
- 保留实验 2 的残差网络和参数设置
- 改动：启用 HDF5 中的脑掩膜：`data.use_brain_mask: true`
- 改动：损失只在掩膜内计算，并按掩膜内的复数像素数量归一化

此前的实现虽然将背景乘以零，但仍使用整张图像的像素数求平均，背景区域会稀释脑组织区域的误差。本实验修正了这一点，重点约束脑组织内部的运动伪影和结构细节。

## 结果比较方法

每个实验完成后，使用对应的最佳权重运行整合评估脚本，并比较：

1. 总体和各运动类型的预测 MSE；
2. `m02` 等轻污染案例是否被过度修改；
3. `sub-10` 输入较清晰时，预测是否仍优于输入；
4. 预览图中的脑组织边缘和细节是否保留；
5. 预测图与输入图之间的差异是否主要集中在伪影区域。

脑掩膜实验与残差实验的结果应分别保存在独立目录中，不能覆盖已有实验。
