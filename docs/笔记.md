## tmux 的使用

### 基本使用

创建新 tmux 会话:
```bash
tmux new -s learn-img
```

### 重新连接 VS code 后打开 tmux

查看当前有哪些 tmux 会话:
```bash
tmux ls
```

接入(恢复)某个会话:
```bash
tmux a -t learn-img-formal
```

删除某个会话:
```bash
tmux kill-session -t 会话名
```
